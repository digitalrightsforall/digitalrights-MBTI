# 结果页面优化方案：行动建议 & 内容推荐

## 背景与目标

当前结果页面（`page.tsx`）在用户完成测评后，仅展示人格解读和维度拆解，缺少**具体的行动指导**和**内容推荐**。用户可能会感到"测完就结束了"，缺乏后续 Engagement。

**优化目标：**
1. 给用户提供 **可落地的微行动建议**，让测评产生实际价值
2. 推荐站内 **相关内容**，引导用户深入学习数字权利知识
3. 引导用户 **参与社区**，形成长期粘性

---

### 2.1 「你的数字行动清单」模块

**数据来源：** 利用 `personas.json` 中已有的 `advice` 字段，将其拆解为 **3-5 个可勾选的微行动**。

**设计原则：**
- 每个行动都是 **5 分钟内可完成** 的小任务
- 降低心理门槛，从"小行动"开始
- 提供 **进度保存**（localStorage），让用户感知自己的成长

**交互形式：**
- 卡片式展示，每个行动是一个可点击的 Checkbox
- 点击后显示 ✅ 动画 + 鼓励文案
- 进度可保存，下次访问时显示已完成状态

**行动类型库（按维度推荐）：**

| 维度特征 | 推荐行动类型 |
|---------|------------|
| S (主权型) | 检查隐私设置、参与开源隐私工具项目 |
| U (效用型) | 开启双重验证、了解数据授权条款 |
| C (审慎型) | 阅读算法解释权相关法律、使用隐私计算工具 |
| O (乐观型) | 尝试 AI 辅助工具、学习提示词工程 |
| M (掌控型) | 配置"人类在环"权限、审计 Agent 决策日志 |
| D (委托型) | 设置 AI 使用边界、开启使用通知 |
| P (积极型) | 分享测评结果、参与社区讨论 |
| R (响应型) | 设置每月一次的隐私检查提醒 |

---

### 2.2 「深入学习」内容推荐模块

**数据来源：** 基于用户人格类型，推荐 `research/` 目录下的文档。

**内容池：**

| 内容 | 适用人格类型 | 推荐理由 |
|-----|------------|---------|
| `deep-research-report.md` | 所有类型 | 全面了解数字权利现状 |
| `assessment-methodology.md` | C/P 类型 | 了解测评背后的方法论 |
| `personality-personas.md` | 所有类型 | 了解其他 15 种人格 |
| `framework-definition.md` | M/P 类型 | 深入理解四维框架 |
| `testing-cheat-sheet.md` | U/D 类型 | 快速了解数字生存技巧 |
| `ai-image-prompts.md` | O/D 类型 | AI 实用技巧 |

**推荐策略：**
1. **主推荐（1篇）**：基于第一维度（S/U）匹配
2. **次推荐（1篇）**：基于第四维度（P/R）匹配
3. **泛推荐（1篇）**：与当前热点或新内容挂钩

**UI 设计：**
- 横向滚动卡片，每个卡片包含：
  - 标题
  - 简短描述（截取前 50 字）
  - 阅读时间估算
  - 人格匹配标签（如 `#主权型` `#审慎型`）

---

### 2.3 「加入社区」模块

**引导目的：**
- 将测评用户转化为社区参与者
- 提升 putongren.org 的回访率

**内容方向：**
- **参与讨论**：链接到社区讨论区（飞书群/微信群/论坛）
- **投稿分享**：分享你的数字权利故事
- **成为志愿者**：协助推广测评、翻译内容、活动组织

**UI 设计：**
- 简洁的 3 栏按钮组
- 每个按钮有图标 + 简短描述
- 点击后打开新窗口或弹窗

## 五、优先级与实施计划

### Phase 1: MVP（1-2天）
- [ ] 利用现有 `advice` 字段，生成静态行动列表

- [ ] 新增「加入社区」模块，链接到 putongren.org

### Phase 2: 增强（3-5天）
- [ ] 扩展 `personas.json`，新增 `actions` 字段
- [ ] 实现 Checkbox 可交互和进度保存
- [ ] 根据人格类型动态推荐内容

### Phase 3: 完善（1周+）
- [ ] 新增 `contents.json` 内容管理
- [ ] 实现内容预览弹窗
- [ ] 添加完成所有行动的成就徽章

## 六、风险与注意事项

1. **不要过度设计**：MVP 先验证用户是否愿意点击行动项，再迭代
2. **隐私合规**：进度保存仅用 localStorage，不上报个人数据
3. **内容时效性**：research 目录内容需定期更新
4. **移动端适配**：卡片需在窄屏下依然美观
